# magpie-freepi

FreePi ([freepi.ai](https://freepi.ai)) as a provider in [magpie](https://usemagpie.ai).

This is the scaffold: the package magpie reads, the provider it declares, and the contract written
down in [`docs/magpie-plugin-contract.md`](docs/magpie-plugin-contract.md). The sign-in, the
provider's requests and its daily allowance arrive in the pull request that follows.
